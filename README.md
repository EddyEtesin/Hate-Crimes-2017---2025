# 📊 Hate Crimes Data Analysis (2017–2025)

This project analyzes reported hate crimes from 2017 to 2025, focusing on temporal trends, offense types, geographic patterns, and bias motivations. The analysis was conducted in Python using Jupyter Notebook.

## 📁 Dataset

- **File**: `Hate_Crimes_2017-2025.csv`
- **Fields**:
  - Incident details (date, location, offense type)
  - Victim age and count
  - Bias motivation (e.g., anti-Black, anti-Gay)
  - Geographic info (ZIP, APD Sector, Council District)

## 🧪 Analysis Summary

### Time-Based Trends
- Yearly trend of hate crimes (2017–2025)
- Plans to explore monthly and day-of-week variations

### Offense & Victim Analysis
- Top 10 most common offenses in hate crimes
- Incidents involving victims under age 18

### Bias-Driven Insights
- Most common types of bias
- Heatmap of bias vs. offense location

### Geographic Distribution
- Frequency of incidents by APD Sector
- Insights into clustering of crimes

## 📈 Visualizations

- **Line plots** for trends over time
- **Bar charts** for offense and bias counts
- **Heatmaps** for location vs. bias relationships

## 🛠️ Technologies

- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
